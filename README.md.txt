# Smart Health Monitoring & Sleep Analysis System

An ML-based web application that predicts sleep quality and detects 
sleep disorders using Python and Streamlit.

## Features
- Sleep quality prediction (Random Forest R² = 0.984)
- Sleep disorder classification — Insomnia & Sleep Apnea (88% accuracy)
- Interactive Streamlit dashboard
- Personalized health suggestions & 7-day wellness plan
- Downloadable PDF health report

## Technologies Used
Python, Pandas, NumPy, Scikit-learn, Streamlit, Matplotlib, 
Seaborn, ReportLab, Joblib

## Dataset
Sleep Health and Lifestyle Dataset — Kaggle

## How to Run
pip install -r requirements.txt
streamlit run app.py
